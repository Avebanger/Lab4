# Домашнее задание к работе 3

## Условие задачи
Написать и отладить программу определения силы притяжения между двумя телами с задаваемыми массами и заданном расстоянием между ними.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Задать исходные данные:
   - `a` — масса первого ингредиента
   - `b` — масса второго ингредиента
   - `c`  — масса третьего ингредиента
4. Проверить кратность каждой массы ингредиента на 3
5. Вывести результаты проверки условия.
6. **Конец**

## 2. Реализация программы
```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>
int main()
{
	setlocale(LC_ALL, "Rus");
	int a, b, c;
	printf("Введите массу элементов a,b,c через пробел: ");
	scanf("%d %d %d", &a, &b, &c);
	if (a % 3 == 0 && b % 3 == 0 && c % 3 == 0)
	{
		printf("Реакция успешно запущена.");
	}
	else
	{
		printf("Реакция не была запущена");
	}

}
```
## 3. Результаты работы программы
